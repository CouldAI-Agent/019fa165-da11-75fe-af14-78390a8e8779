# Ekologi & Pentahelix App

Aplikasi edukasi ini dirancang untuk memberikan pemahaman mengenai konsep Ekologi dan bagaimana model kolaborasi Pentahelix dapat diimplementasikan untuk meningkatkan kualitas pelayanan publik yang berkelanjutan.

## Fitur Utama
- **Materi Ekologi**: Penjelasan dasar tentang pentingnya ekologi dalam pelayanan publik.
- **Model Pentahelix**: Pengenalan lima elemen utama (Pemerintah, Akademisi, Bisnis, Masyarakat, dan Media) dalam pembangunan kolaboratif.
- **Sinergi Pelayanan Publik**: Bagaimana kelima elemen bekerja sama untuk menciptakan kebijakan pro-lingkungan.
- **Contoh Implementasi**: Studi kasus nyata seperti pengelolaan sampah terpadu dan transportasi rendah emisi.

## Teknologi
- Flutter (Dukungan penuh untuk Web, Mobile, Desktop)
- Material 3 Design
- Layout Responsif

## Cara Menjalankan Aplikasi
1. Pastikan Flutter SDK telah terinstal.
2. Jalankan `flutter pub get` untuk mengunduh dependensi.
3. Jalankan aplikasi menggunakan perintah:
   ```bash
   flutter run
   ```
